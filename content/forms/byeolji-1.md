## 1단계. 방향

- [ ] 기도와 예배의 시간을 줄이거나 밀어내지 않는다
- [ ] 핵심 역량(사고력·영어·수학) 중 기르는 역량을 하나 이상 분명히 제시할 수 있다. 또는 검정고시 합격에 직접 필요하다
- [ ] 개별 독서로 충분히 채울 수 있거나 대학 진학 이후에 배워도 되는 내용이 아니다
- [ ] 제10조의 지향하지 않는 교육에 해당하지 않는다

외부 기관 요청인 경우, 학교에 주는 관계적 유익:

## 2단계. 연결

- [ ] 기여하는 졸업생 상(별표 1):
- [ ] 기록이 남는 관통 기준표의 항목(별표 2):
- [ ] 기존 과목·프로그램과 목적이 겹치지 않는다. 겹치는 경우 기존 것을 보완하는 방안을 먼저 검토하였다

## 4단계. 실행 (신규 도입)

- [ ] 한 쿼터 동안 최소 규모로 시범 운영할 수 있다
- [ ] 쿼터의 성격(별표 4)에 맞는 시기이다
- [ ] 해당 쿼터에 새로 시작하는 안건이 2개 미만이다
- [ ] 일정이 바뀌는 학생·학부모 안내 계획이 있다
- 계속 운영 여부를 판단할 기준 (예: 참여율, 결과물, 레벨 변화):

## 4단계. 지난 1년 운영 결과 (연간 재심사)

- 운영한 시기와 횟수:
- 처음 정한 판단 기준과 실제 결과 (참여율, 결과물, 레벨 변화 등):
- 학생·학부모·교사의 의견:
- [ ] 목적이 다른 과목·프로그램과 겹치지 않는다
- [ ] 지금의 시간·인력·예산으로 다음 해에도 운영할 수 있다
