# 레퍼런스 자료

학칙과 시스템을 다듬을 때 참고하는 실제 운영 자료. 학칙(`content/hakchik.md`)이 기준이고, 이 자료는 "지금 실제로 어떻게 하고 있는가"를 보여 준다. 둘이 다르면 학칙을 고칠지, 운영을 학칙에 맞출지 교사회에서 정한다.

## 폴더

| 폴더 | 내용 | git |
| --- | --- | --- |
| `brand/` | 학교 로고 (`public/hils-logo.png`로도 복사해 사이드바에 사용) | 올림 |
| `admission/` | 기존 입학 서류 3종 원본 (hwp, hwpx): 입학원서·학부모 질문지, 자기소개서, 학부모 동의서 및 서약서. 빈 양식 | 올림 |
| `calendar/` | 학사일정: 2027 2종(글로벌 캠퍼스 행 포함판, 포스터판), 2021 PDF. 지난해 원본은 `public/calendar/연도.png`로도 두어 학사일정 화면에서 연도별로 보여 준다 (2021 PDF·PNG, 2022·2024 JPG) | 올림 |
| `private/` | 실제 학생·교직원 이름이 들어간 자료 | **올리지 않음** (`.gitignore`) |

`roster.csv`가 없으면 시스템은 가상 시연 명단(`lib/seed.ts`)으로 동작한다.

## 입학 서류 (admission/)와 학칙 비교 — 0.9.6에서 반영

| 기존 서류 | 학칙 | 반영 |
| --- | --- | --- |
| 입학원서·학부모 질문지 | 제28조 제1항 제3호 "입학 원서 제출" (서식 없음) | 별지 9로 신설. **주민등록번호 칸은 뺌**(법령 근거 없이 수집 불가, 생년월일로) |
| 자기소개서 | 서식 없음 | 별지 10으로 신설 |
| 학부모 동의서 및 서약서 | 제28조 제4항 학생 기록 수집·이용 동의, 제15조 제2항 가정 연계 | 별지 11로 신설. 서약 문구는 학칙 조항과 연결하고, **기록 수집·이용 동의(2부)를 새로 넣음**. 보관 기간은 빈칸(학교 결정 필요) |
| 서약서 "비인가 학교로써" | 제2조: 교육청에 등록한 학교 | "정부 재정 지원이 없음"으로 고침 |
| 서약서 "중도 이탈 시 6개월 전 상담" | 제34조 제1항 제1호: 보호자 신청 시 퇴교 (사전 상담 기간 없음) | 서약서에는 남김. **학칙에 넣을지 결정 필요** |
| 서약서 "훈육·근신·퇴학 최종결정권은 학교" | 제35조 제1항 학교장 최종 판단, 제34조 제2항 퇴교 절차 | 학칙 절차를 따른다고 고침 |

## Supabase로 옮길 때 가져갈 실제 자료

| 자료 | 지금 위치 | 옮길 곳 |
| --- | --- | --- |
| 학생 명단 (반·학년·성별·당번) | `private/roster.csv` + 화면에서 고친 내용 | `students` |
| 교직원 (역할·담임·과목·영역·강점) | `private/staff.csv` + 교직원 화면 | `staff` |
| 2027 학사일정 | `lib/calendar.ts` 기본값 + 학사일정 화면 | `calendar_events` |
| 지난 학사일정 원본 | `public/calendar/*` | Storage + `calendar_events`(필요하면 입력) |
| 교과 로드맵 (2025-03 보고서에서 옮김) | `lib/roadmaps.ts` + 교과 로드맵 화면 | `report_templates.roadmaps` |
| 입학 서류·별지 원문 | `admission/*.hwp`, `content/forms/*.md` | Storage (원본), 코드 (템플릿) |
| 화면에서 쓴 기록 (보고서·면담·출결·성적·서식·회계 등) | 브라우저 localStorage `hils-hub-demo-v2` | 각 테이블 (`supabase/schema.sql`) |

브라우저에 쌓인 기록은 사이드바 "데이터 초기화"를 누르면 지워지므로, 이관 전에는 누르지 않는다. 이관 스크립트는 localStorage JSON을 내보내 테이블로 넣는다.
